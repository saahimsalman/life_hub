Saahim's Life Hub — installable web app

This folder is a complete static website. Nothing here talks to a server; your data stays in the browser you use it in.

TO USE ON A PHONE (home-screen app, works offline):
1. Put this folder on any free static host, e.g. GitHub Pages (github.com -> New repository -> upload these files -> Settings -> Pages -> deploy from main) or Netlify Drop (app.netlify.com/drop: drag the folder in).
2. Open the resulting https:// link on your phone.
3. iPhone: Share -> Add to Home Screen. Android: menu -> Install app / Add to Home screen.

TO USE ON A LAPTOP WITHOUT HOSTING:
Open index.html (or the single-file SaahimsLifeHub.html) directly in Chrome, Edge, Firefox or Safari. Bookmark it.

BACKUPS: Settings -> Export backup gives you a JSON file; Import it on another device to move your data.
